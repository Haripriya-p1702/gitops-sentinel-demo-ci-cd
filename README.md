# GitOps Sentinel Demo - Kubernetes

This repository is intentionally built with insecure and non-optimized configurations to demonstrate the capabilities of the **GitOps Sentinel** autonomous DevOps agent.

---

## 🚨 Purpose

This project simulates real-world DevOps mistakes so the agent can:

- Detect issues using reasoning
- Fix them automatically
- Create pull requests with explanations
